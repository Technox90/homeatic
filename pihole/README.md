# Pi-hole

Dieser Ordner ist für die eigene Pi-hole-Konfiguration vorgesehen.

## Geplante Inhalte

- lokale DNS-Einträge
- eigene Allowlist
- eigene Blocklist
- CNAME-/DNS-Konfigurationen
- Dokumentation der verwendeten Listen

Der Proxmox-Installer richtet Pi-hole zusammen mit **Unbound** und dem **Pi-hole Prometheus Exporter** ein.
