# Lokale DNS-Einträge

Hier kommen die eigenen lokalen DNS-Einträge für Pi-hole hinein.

Empfohlene Ablage:
- `custom.list` für Hostname -> IP-Zuordnungen
- zusätzliche Dokumentation bei Bedarf

Beispiel:

```text
192.168.178.100 pve.lan
192.168.178.103 pihole.lan
```

Keine Passwörter, API-Tokens oder andere Secrets in dieses Repository committen.
